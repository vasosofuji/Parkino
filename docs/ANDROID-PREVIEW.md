# Android private test build

The connected APK uses https://parkino-api.onrender.com and the shared Supabase database. It does not need Expo Go or a Metro server. Android uses Leaflet/OpenStreetMap without a Google Maps key. Map tiles and writes require internet; the cached parking catalog can be browsed offline. Coverage and prices remain incomplete.

The APK is compiled in release mode and signed with the generated Android test keystore. It is for private testing, not Play Store publication. Both ARM64 and ARMv7 devices are included, with Android 7 (API 24) or newer required. Actual hardware installation is not verified on this PC because no Android device is attached.

## Rebuild locally

Use the installed Android SDK and JDK 17. Native files are generated by Expo; changes belong in app configuration or config plugins. The script copies tracked and nonignored source into a fresh short directory under `C:\pb`, installs the lockfile, and generates/compiles Android there. It excludes private `.env` files and restores the caller's environment. A short real path avoids Node/Gradle disagreements about drive aliases; the config plugin enables CMake filename hashing. Build directories are retained for diagnostics.

```powershell
.\scripts\build-apk.ps1 -ApiUrl https://parkino-api.onrender.com
```

This produces `preview/Parkino-connected.apk` with live contributions enabled. Use the explicit `-OfflinePreview` switch only for a disconnected catalog preview. Keep the signing identity consistent for updates; local test signing is not the Play Store release signing setup.

## Launch and field verification

Connect a phone with USB debugging enabled and approve its debugging prompt. Check `adb devices`, install the connected APK with `adb install -r preview/Parkino-connected.apk`, then launch `mk.parkskopje.app/.MainActivity`. Use `adb logcat -b crash -d` if it exits. Do not uninstall an existing installation just to bypass a signing mismatch: that deletes its device identity.

Before sharing broadly, verify username/terms onboarding, denied and precise GPS permissions, GPS off/on recovery, returning from the background, center-pin destination selection, draggable vertices, camera/gallery uploads and edits shared between two phones on mobile data. Stay stationary inside a parking perimeter for at least 35 seconds with a fresh fix accurate to 25 m or better. Arrival detection runs while the app is in the foreground.

## Temporary download link

`scripts/serve-apk.py` binds to 127.0.0.1:8766. It serves a simple landing page and `preview/Parkino-connected.apk` only. Other paths return 404; uploads and directory listings are unsupported. A Cloudflare quick tunnel can point to this server. The temporary link stops working if the PC, tunnel or download server stops. Restart an already-running download server after updating its script.

The map bridge is independently checkable through `npx tsx scripts/preview-native-map.ts`. This writes `preview/native-map.html`, which is for local testing and is not served by the public APK download server. Vendored Leaflet code and CSS retain the BSD-2-Clause license in `src/components/LEAFLET-LICENSE.txt`.
