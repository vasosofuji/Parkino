# Android phone preview

This preview bundles the catalog and native UI into an installable APK. It does not need Expo Go or a Metro server. Android falls back to Leaflet/OpenStreetMap without a Google Maps key. Map tiles require internet; the parking catalog can be browsed offline. Coverage and prices remain incomplete.

The APK is compiled in release mode and signed with the generated Android test keystore. It is for private testing, not Play Store publication. Both ARM64 and ARMv7 devices are included, with Android 7 (API 24) or newer required. Actual hardware installation is not verified on this PC because no Android device is attached.

## Rebuild locally

Use the installed Android SDK and JDK 17. Native files are generated by Expo; changes belong in app configuration or config plugins. The build script creates a temporary unused drive alias to the project parent, avoiding Windows Ninja filename limits, then removes the alias after the build. It restores the caller's environment variables. The original project stays in the parking folder.

```powershell
.\scripts\build-apk.ps1
```

`EXPO_PUBLIC_OFFLINE_PREVIEW=1` disables contribution API requests for this pilot binary. No localhost API address is sent from the phone. To enable live reporting, rebuild without that flag and set a reachable `EXPO_PUBLIC_API_URL`. Exposing the local API publicly requires separate user authorization; only APK sharing was authorized for this preview.

## Temporary download link

`scripts/serve-apk.py` binds to 127.0.0.1:8766. It serves a simple landing page and `preview/ParkSkopje-preview.apk` only. Other paths return 404; uploads and directory listings are unsupported. A Cloudflare quick tunnel can point to this server. Never tunnel the entire API without separate authorization. The temporary link stops working if the PC, tunnel or download server stops.

The map bridge is independently checkable through `npx tsx scripts/preview-native-map.ts`. This writes `preview/native-map.html`, which is for local testing and is not served by the public APK download server. Vendored Leaflet code and CSS retain the BSD-2-Clause license in `src/components/LEAFLET-LICENSE.txt`.
